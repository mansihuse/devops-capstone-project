
# DevOps Capstone Project

## Project Overview
This project focuses on developing a Customer Accounts microservice using DevOps practices.

## Objectives
- Create and manage a GitHub repository.
- Create and prioritize user stories.
- Build a product backlog.
- Plan the first sprint using a Kanban board.
- Apply labels and story points.

## Tools Used
- GitHub
- Git
- GitHub Issues and Projects

## Project Scope
The project uses user stories and sprint planning to organize the development of the Customer Accounts microservice.
